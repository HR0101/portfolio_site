# 惑星を中心に情報が切り替わる展示

更新日：2026-11-08。

要件：全体を通す固定ロゴではなく、一つの世界観として続く場面を作る。中央には同じものがあり、スクロールで情報が変わる。惑星の案を採用する。

対象をHeroに続く注目アプリの区間とし、3つのカードを交換する構成から、1つの惑星・1台の表示窓を保つ構成へ変更した。その他の作品一覧やSkillsのカードはこの変更の対象外。

## 構成

- 中央：ベクターで描いた白黒の惑星と、同じディスプレイ。要素の位置と寸法を保つ。
- 左：アプリ名・見出し・短い説明。
- 右：主な機能と、紹介ページ／GitHubへの通常のリンク。
- 上：現在のアプリと直接選択。下：スクロール進捗、自己紹介へ進むリンク。
- BusTimeApp → TeleDeck → Tsumugiの順に切り替わり、上へ戻すと同じ順序を逆にたどる。

## 動き

十分なPC画面では3画面分の区間で舞台をsticky表示。現在のスクロール位置から章を決め、ホイールやタッチの入力を取り込んでスクロール量を変更する処理は設けていない。

実画面・見出し・説明・機能を240msのopacityで同時に切り替える。惑星の位置は固定し、向きだけを区間内で24度動かす。状態更新は章が変わるときだけで、毎フレームReactを再描画しない。

直接選択・矢印キー・Home / Endは即時に切り替え、対応する章の中央へ着地する。小画面・低い画面・reduced motionでは固定区間を設けず、同じ展示を選択ボタンで操作できる。

入口の空の帯は、惑星の章の背景色へ着地するよう終端色を調整した。

タイムライン・固定する要素と理由・見た目の確認点：[設計](../../plans/planet-showcase.md)。

## 実装先

- `src/sections/ProductShowcase.tsx` / `.css`：共有の舞台、アプリ情報、通常リンク、選択操作、sticky区間。
- `src/lib/showcaseStory.ts`：進捗・章・直接選択の着地計算。
- `public/illustrations/app-planet.svg`：惑星のベクター。新しいWebGL描画ループやアニメーション依存は追加していない。
- `src/sections/Hero.module.css`：空の帯の終端色。
