# Heroから紹介へ続く点描の惑星

2026-11-09。前日のSVG惑星の初期案を、ユーザー指定の「点で表現した惑星」と「最初の右側から中央へ来る」構成に変更。

- Hero右側の主役を点群の球体へ変更。既存の地図マスクを3D球面へ配置し、奥行きで点の明るさを変える。
- DotPlanetのCanvasは一つ。同じ描画要素をHero右側から中央へ移し、紹介区間では位置・大きさを固定する。
- 実画面と説明をBusTimeApp→TeleDeck→Tsumugiの順に切替。通常スクロール・逆方向・途中へのジャンプに追従する。
- 小画面はタブで紹介。reduced motionは回転・連続移動・長い固定区間を省く。
- Heroと移動中は80秒/周で自転し、中央到着後は更新時だけ描画。画面外と非表示タブでは停止し、復帰時も角度を保つ。DPR上限2。旧HeroUniverseのRHドラッグ実装は保存しているが現在表示しない。
- 追加修正：暗い背景への上書きを外し、Hero直後の紫→青→水色へ広がる元の円形グラデーションを復元。
- テーマ修正：Hero・紹介エリアをライトで白地と黒文字、ダークで黒地と白文字へ反転。点群・表示枠・罫線・CTA・ターミナルも切替。アイコンと実画面は原色を保持する。Canvasは再生成せずCSSで色を反転し、自転とスクロールの状態を保つ。
- Hero拡張：地球を初期実装の1.5倍に拡大し、スマートフォンでは画面幅へ制限。4アプリを球面上の地点に配置し、点群の描画フレームと同じ回転角で同期。裏側は薄くし、hover/focus中は自転を休止。紹介エリアへの到着前に4アイコンをフェードアウトする。

Chrome Canary実画面でHero右側、中央への移動途中、中央のBusTimeApp・TeleDeck表示を確認。惑星と表示窓の位置を保った切替を確認した。

テーマボタンを実際に操作し、HeroとBusTimeApp紹介でライト／ダーク双方の背景・文字・点群・表示枠を確認。変更後も型チェック・対象Lint・モーションテスト26件が通過。

Hero拡張後は両テーマの4アイコンと中央への切替を実画面で確認。TabキーでSubghostへ移動でき、自転が止まった状態でフォーカス枠が見えることを確認した。球面地点と表裏・拡大率・小画面幅の3テストを追加し、モーションテスト29件、型チェック、対象Lintが通過。

## 地球の精細化と小型惑星への連続変化

参考スクリーンショットに合わせ、PCでは地球を右端から大きく見せる構図へ変更。Natural Earth 1:50mの海岸線から専用の480×192マスクを生成し、等面積の細かい陸地点を追加。上側の暖色光と青い大気の縁をSVGで重ねた。ライト／ダークの配色、自転、球面上のアプリを維持している。

位置・寸法・点群の精細度・大気の不透明度を同じスクロール進捗で変え、中央では従来の小型惑星へ着地する。Canvasを交換せず、最大2048pxの描画領域を大きなHeroから縮小後まで再利用。ターミナルと統計を左側へ収め、大きな地球との重なりを解消した。

生成元：world-atlas@2.0.2のland-50m.json（Natural Earthデータはパブリックドメイン）。再生成は`scripts/generate-planet-land.mjs`。既存のローディング用地図は変更しない。

Chrome Canaryでライトの大きな地球、ダークの大気と細かな点、縮小途中、中央の従来サイズのTeleDeck紹介を確認。点群の交差と寸法・精細度の連動を2テスト追加し、モーションテスト31件が通過。

検証：`npm run typecheck`、変更したTS/TSXのESLint、`npm run test:motion`。球面座標・投影・裏側の減光・バッファ再利用・移動の端点と逆方向を6件追加した。devサーバー稼働中のため`.next`を消すproduction buildは実行していない。
