# 自己紹介カードの復元と固定表示

元の4項目（情報系の学生、iOS / macOSアプリ開発、組込み・電子工作、「Trust」を軸に）とアイコン・線画・配色を復元。端末モデルと動画の実験用コンポーネント、描画・seekの補助コードを削除した。

参考サイトのA05/A06を応用。PCは表示位置を固定し、4枚のカードを同じ場所で切り替える。項目選択・カード番号・下部の進捗線が同じスクロール位置を使う。カード全体を200msで切り替え、子要素を個別に遅延させない。逆スクロールの移動方向も反転する。直接選択とキーボードは即時に更新する。

スクロール計算は既存の`showcaseStory.ts`を共用。小画面とreduced motionでは固定区間を使わず、4項目を直接選択できる。

検証：型検査、変更コンポーネントのESLint、既存モーションテスト31件を通過。Chrome Canaryで元のカード表示、スクロールによる次カード、逆スクロール、Home/Endキーによる最初・最後への切替、約560 CSS pxでのカード表示と直接選択、通常幅へ戻した後の復帰を確認。
