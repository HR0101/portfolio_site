# ポートフォリオのデザイン方針

白・黒・淡いグレーを基調に、実際の作品画面とターミナルで「信頼」とものづくりの過程を見せる。色や動きは、ページの内容と操作を理解するために使う。

## 共通の基準

- `src/app/design-tokens.css` に背景、文字、区切り線、アクセント、角丸、影、セクション間隔、イージングの役割別変数を置く。`.dark` で同じ役割の値を切り替える。
- `src/app/globals.css` の Tailwind カラーとフォントは既存のユーティリティの基準として残す。新しい共通コンポーネントでは役割別の `--site-*` を優先し、対象範囲を確認してから既存の指定を移行する。
- 見出しは `SectionHeading` に揃え、セクション番号・短い英字ラベル・日本語見出し・説明の順で情報を整理する。
- カード、リンク、フォームはライト／ダークの両方で文字と操作状態が分かるようにする。色だけで情報やエラーを伝えない。

## 作品固有の表現

作品紹介では実際の画面や公式アイコンを使い、BusTimeApp の青、Tsumugi の生成りと藍、Subghost のシアンと紫、EkiHub の路線を思わせる青緑などを作品内の表現に使う。詳細ページの `product.module.css` は作品固有の変数を持つため、共通トークンの変更で一律に塗り替えない。

## 動き

登場は短い段階表示、スクロールは内容の流れ、ホバーは操作への反応に使う。要素の移動は原則として `transform` / `translate` と `opacity` を使い、スクロール処理は共通の `scrollObserver` を利用する。画面外で不要なループは止める。`prefers-reduced-motion: reduce` では視差・浮遊・自動演出を抑え、内容と操作を静止状態で提供する。

## 変更時の確認

トップ、メニュー、作品一覧、詳細ページをライト／ダークとスマートフォン幅で確認する。キーボードでの移動、タブ切り替え、フォームのエラー、動きを減らす設定、画像の代替テキストも確認する。ターミナル風の演出は Hero の要素として維持する。
